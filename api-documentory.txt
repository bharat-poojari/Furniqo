Furniqo Backend API Documentation

Base URL: /api/v1

Health
- GET /api/v1/health
  - Description: Health check endpoint
  - Access: Public

Admin
- GET /api/v1/admin/dashboard/stats
  - Description: Fetch admin dashboard statistics
  - Access: Admin only
- GET /api/v1/admin/health
  - Description: Check admin system health
  - Access: Admin only

Cart
- GET /api/v1/cart
  - Description: Get current user's cart
  - Access: Private
- POST /api/v1/cart/add
  - Description: Add item to cart
  - Access: Private
- PUT /api/v1/cart/update/:itemId
  - Description: Update cart item quantity
  - Access: Private
- DELETE /api/v1/cart/remove/:itemId
  - Description: Remove item from cart
  - Access: Private
- DELETE /api/v1/cart/clear
  - Description: Clear entire cart
  - Access: Private
- POST /api/v1/cart/sync
  - Description: Sync guest cart items to authenticated user cart
  - Access: Private

- POST /api/v1/categories

- PUT /api/v1/categories/:id

- DELETE /api/v1/categories/:id
